# A Little Place in Time — Birthday OS

**Birthday edition:**
**Konsep:** Elegant & Nostalgic  
**Versi:** 1.0 preview, siap dicoba lokal.

## Cara membuka

1. Ekstrak ZIP.
2. Buka `index.html` menggunakan Chrome, Edge, Firefox atau browser HP.
3. Tidak perlu server, hosting, instalasi, login, atau koneksi internet.

Seluruh kode, desain, teks, serta ilustrasi CSS berada di dalam **satu file `index.html`**, sehingga mudah dipindahkan atau diunggah ke hosting statis.

## Fitur

- Opening empat adegan (undangan, ulang tahun, harapan, masuk ke OS), bisa dilewati dan diulang.
- Memory Desk dengan enam ruang:
  1. Birthday Letter, lima halaman; print / simpan PDF melalui menu cetak browser, serta salin teks.
  2. Our Little Cinema: dua film, tiket seat 14 & 17, dan catatan.
  3. Little Chapters: tiga tulisan pendek.
  4. Open When: enam amplop.
  5. Keepsake Box: enam benda/cerita.
  6. One Last Wish: kartu penutup yang bisa disimpan sebagai PNG.
- Tampilan adaptif untuk laptop & HP, navigasi keyboard, reduced motion, dan bunyi singkat opsional.
- Menyimpan status intro/ruang yang pernah dibuka di browser setempat, tanpa mengirim data ke server.

- Isi surat memakai versi revisi pengguna, termasuk bagian *“Kita masih temenan kan yaa, hehe..”*.
- Film dan buku direpresentasikan oleh ilustrasi abstrak buatan CSS, **bukan poster resmi** atau foto pribadi.
- Sebelum dikirim sebagai hadiah, tinjau ulang seluruh tulisan dan ejaan serta uji pada HP tujuan.
- Untuk menggunakan menu **Cetak / Simpan PDF**, buka surat, tekan tombol tersebut, lalu pilih *Save as PDF / Simpan sebagai PDF* di dialog cetak browser.
- Tidak ada akun, analytics, font dari CDN, atau gambar eksternal.
